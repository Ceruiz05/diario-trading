# Diario de trading

Dashboard personal de mis cuentas Apex (NinjaTrader 8 + Rithmic).

- `Actualizar.bat`: lee las operaciones de NinjaTrader, las cifra y las sube a este repo.
- La página pide contraseña: los datos en `data.json` están cifrados (AES-GCM).
- Ajustes (cuentas, comisiones, retiros) en `local/config.json`, que no se sube.
